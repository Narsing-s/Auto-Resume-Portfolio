## 📁 Project Structure

```text
Auto-Resume-Portfolio/
├── index.html       # Complete portfolio UI and interactions
└── README.md        # Project documentation
```

The current implementation is intentionally lightweight: the portfolio runs as a static website without a backend, database, authentication service, or build step.

## 🚀 Run Locally

Because this is a static site, you can open `index.html` directly in a browser.

For a local development server, use any static HTTP server, for example:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## 🌐 Deploy

This project can be deployed to any static hosting platform, including GitHub Pages, Vercel, Netlify, or a traditional web server.

No environment variables are required for the current static implementation.

## 🎨 Theme & UI

The portfolio supports both dark and light themes. The selected theme is stored locally in the browser so it remains available when the visitor returns.

The interface also adapts navigation, spacing, typography, cards, and layout for smaller screens.
